#  Dynamic Weather Dashboard

A simple and responsive web app built with **HTML, CSS, JavaScript**, and **Bootstrap** that allows users to check the current weather of any city using the **OpenWeatherMap API**.

---

##  Features

- Search weather by city name
- Real-time data: temperature, humidity, wind speed, and description
- Clean and responsive UI using Bootstrap
- Error handling for invalid cities

---

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- OpenWeatherMap API

---

##  Getting Started

###  1. Get an API Key

- Sign up at [OpenWeatherMap](https://openweathermap.org/api)
- Navigate to **API Keys** and copy your API key

###  2. Clone the Repository

```bash
git clone https://github.com/your-username/weather-dashboard.git
cd weather-dashboard
```

###  3. Insert Your API Key

Open `script.js` and replace:

```js
const apiKey = "YOUR_API_KEY";
```

with your actual key:

```js
const apiKey = "abcd123yourkey";
```

###  4. Run the App

Open `index.html` in your browser.
